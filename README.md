# WorkFlow AI Hub

Build a web application called:

BLESSING LUMNKA'S WORKFLOW AI

Student Developer:

Blessing Lumnka

Purpose:

WorkFlow AI is a workplace productivity assistant designed to help users with common tasks such as writing professional emails, summarising meeting notes, organising tasks, conducting initial research, and receiving workplace productivity assistance.

IMPORTANT:

This is a student-developed project. Build the application in a way that allows me, Blessing Lumnka, to understand, demonstrate, test, and explain each feature.

Do not add fake statistics, fake testimonials, fake users, fake company information, or invented performance claims.

Do not claim that features work unless they are actually implemented.

Create ONE integrated application with a dashboard and navigation between the following features:

1. Smart Email Generator

2. Meeting Notes Summarizer

3. AI Task Planner

4. AI Research Assistant

5. AI Workplace Chatbot

APPLICATION DESIGN

Use a clean, professional and original interface.

The application should include:

- Dashboard

- Sidebar navigation

- Responsive desktop and mobile layout

- Clear headings

- Forms

- Buttons

- Loading states

- Error states

- Empty states

- Success notifications where appropriate

Use the application name "WorkFlow AI" consistently.

Show "Blessing Lumnka" in the appropriate developer/about section.

DASHBOARD

Create a dashboard that introduces:

"Welcome to WorkFlow AI"

Subtitle:

"An AI-powered workplace productivity assistant."

Show five feature cards:

- Email Generator

- Meeting Summarizer

- Task Planner

- Research Assistant

- Workplace Chatbot

Do not use invented usage statistics.

SMART EMAIL GENERATOR

Allow the user to enter:

- Recipient

- Purpose

- Key points

- Tone

- Length

Tone options:

- Professional

- Formal

- Friendly

- Persuasive

- Apologetic

Length options:

- Short

- Medium

- Detailed

Generate an editable professional email.

Provide:

- Generate

- Copy

- Regenerate

- Clear

The AI must not invent names, dates, promises, facts, or commitments that the user did not provide.

MEETING NOTES SUMMARIZER

Allow the user to paste meeting notes.

Generate:

- Meeting Summary

- Key Decisions

- Action Items

- Deadlines

- Important Points

If a person, deadline, decision, or fact is not contained in the notes, do not invent it.

Provide:

- Summarize

- Copy

- Clear

- Regenerate

TASK PLANNER

Allow users to create multiple tasks.

Each task should support:

- Task name

- Deadline

- Estimated duration

- Priority

- Optional notes

Priorities:

- High

- Medium

- Low

The AI should help organise tasks according to urgency, priority and deadlines.

Display:

- Prioritised tasks

- Suggested order

- Suggested schedule

Allow users to mark tasks as:

- To Do

- In Progress

- Completed

Do not invent deadlines or task requirements.

RESEARCH ASSISTANT

Allow users to enter:

- Research topic

- Research question

- Desired level of detail

Options:

- Quick overview

- Detailed

- Executive summary

Return:

- Overview

- Key findings

- Important concepts

- Insights

- Practical recommendations

- Further research questions

Clearly label AI-generated information and remind users that important information should be independently verified.

Do not fabricate sources or citations.

AI WORKPLACE CHATBOT

Create an interactive chatbot for workplace productivity.

The chatbot can help users with:

- Workplace communication

- Task organisation

- Meeting preparation

- Productivity ideas

- Basic workplace planning

Include:

- User messages

- AI responses

- Loading indicator

- Clear conversation

- Suggested prompts

The chatbot should not pretend to know information that it does not know.

PROMPT ENGINEERING

Structure the AI prompts using:

1. Role

2. Task

3. Context

4. User-provided information

5. Constraints

6. Expected output format

Prompts must instruct the AI not to invent missing information.

RESPONSIBLE AI

Create a Responsible AI section.

Include:

- AI-generated information may contain errors.

- Users should verify important information.

- Users should avoid entering confidential or sensitive information.

- AI-generated emails should be reviewed before sending.

- AI should support human decision-making rather than replace human judgement.

- AI should not fabricate facts, sources, names, dates or decisions.

ABOUT / PROJECT INFORMATION

Create an About section containing:

Project:

WorkFlow AI

Developer:

Blessing Lumnka

Description:

"WorkFlow AI is a student-developed AI productivity application designed to assist users with common workplace tasks."

Do not add other people's names or claim that other people developed the project.

SETTINGS

Include:

- Default email tone

- Research response detail

- Clear session data

- Responsible AI information

PRIVACY AND SECURITY

Do not expose API keys in frontend code.

Use appropriate secure API integration if an external AI API is required.

Do not store sensitive user information unnecessarily.

QUALITY REQUIREMENTS

Make the application functional and understandable.

Do not add unnecessary features simply to make the project appear more advanced.

Every feature should have a clear purpose.

Use clear comments or documentation where useful so that I can understand the important parts of the application.

Before considering the application complete, make sure I can demonstrate each feature and explain what it does, what inputs it uses, what the AI produces, and what its limitations are.
